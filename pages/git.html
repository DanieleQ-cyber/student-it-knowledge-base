Podstawowe informacje o Git

Git to rozproszony system kontroli wersji (DVCS) stworzony w 2005 roku przez Linusa Torvaldsa do śledzenia zmian w plikach i kodzie źródłowym. Umożliwia pracę offline, bezpieczne cofanie zmian oraz równoległą pracę wielu osób nad jednym projektem.

Procedura pracy

  • Najpierw synchronizacja
  • Tworzymy własny nowy branch.
  • Zmieniamy kod / tworzymy własny kod lub pliki
  • Robimy commit oraz odpowiednio go nazywamy
  • Po commicie robimy push
  • Jeśli skończymy to Pull Request

Podstawowe polecenia Git

Polecenie Przykład Opis
git add git add . Przenosi zmiany z katalogu roboczego do przechowalni.
git clone git clone (link) Tworzy kopię istniejącego repozytorium Git.
git commit git commit -m "Opis commitu" Wykonuje commit migawki z przechowalni do historii projektu.
git fetch git fetch origin Pobiera gałąź z innego repozytorium.
git status git status Pokazuje status gita
git branch git branch Pokazuje jakie branche są w repozytorium
git switch git switch feature/html-git Przełącza do brancha feature/html-git
git log git log -n 5 Pokazuje histori commitów
