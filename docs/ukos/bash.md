pwd - pokazuje aktualną ścieżkę w której jesteśmy
ls - pokazuje jakie pliki/foldery są w aktualnej ścieżce
cd - przenosi nas do wybranej lokalizacji
mkdir - tworzy folder
touch - tworzy pusty plik
cp - kopiowanie pliku
mv - przenoszenie pliku
rm - usuwanie
cat - wyświetlenie zawartości pliku
clear - wyczyszczenie konsoli
